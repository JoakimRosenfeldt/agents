# Universal skills

Skills in this directory are shared across supported coding agents.

| Skill | Trigger |
| --- | --- |
| `babysit-pr` | Monitor, watch, follow, or babysit a PR |
| `file-pr` | File, open, create, or submit a PR |
| `file-upload` | Upload, host, publish, or share a file |
| `html-communication` | Present work as hosted HTML |
| `postplan-read` | Read a `postplan.dev` URL |

Keep descriptions trigger-focused and bodies procedural. Keep each skill independent and concise.
